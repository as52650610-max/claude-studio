# 動態字體短片簡報（15–30 秒）

> 適合：副歌或一段歌詞做成 15–30 秒的動態字體短片（抖音、Shorts、Reels、B 站豎屏）。
> 用法：〔〕換成你的內容。短片最怕「每個字都在動」：先定字型系統與每句字的目的，再做動態。
> 背景：[docs/05 歌詞](../../docs/05-lyrics.md)、[docs/08 動態](../../docs/08-motion.md)。

```markdown
# 動態字體短片簡報

## 1. 角色與標準
你是動態字體設計師與剪輯師。標準：〔一看就想存下來的字體設計，像頂尖品牌片的字卡，不是字幕〕。
照 studio 技能的流程做；這是短片，G2 與 G3 可以合併，但檔案都要寫。

## 2. 素材
- 歌曲：audio/〔檔名〕，權利：〔…〕
- 歌詞：〔官方文本路徑〕
- 片段：〔副歌第一次出現／第 33–48 小節〕，用 studio excerpt 切在整小節上，長度 ≤ 〔30〕秒
- 字型：〔Noto Sans TC 可變字重／Noto Serif TC〕（OFL），只用這一套家族

## 3. 方向
- 情緒：〔…〕；顏色：〔底色 hex、字色 hex、一個強調色 hex〕
- 字是畫面的主角，不是字幕：時間單位是字，閱讀單位是詞組
- 不要：每個字都彈跳、所有句子同一種進場、置中加漸層、霓虹光暈、假粗體與假斜體

## 4. 結構
- 規格：9:16 1080×1920，30 fps；保留下方 20% 與右側按鈕欄（平台介面）
- 每一句先寫「字的目的」：介紹／只換一個字（只對變的那個字做遮罩捲動）／選出一個概念／把想法變成動作／收束
- 前 3 秒是鉤子：第一幀就要有字，不能是黑畫面
- 副歌前 2–3 秒只露半句、畫面收縮；拍點那一幀補完整句、畫面打開、低頻落下
- 最後一句停住至少 1.2 秒，做成可以當封面的畫面

## 5. 製作規則
- 時間全部用 at.lyric、at.word、song.T 定址；不寫死秒數
- 字在被唱到時才填滿，預覽的淡字最多早 0.4 秒；字唱多久至少停多久
- 中文按語意斷句；數字和單位不拆開；行首不放句號、逗號
- 一個畫面一個強調色；動態：進場減速、退場加速，單一進場 ≤ 0.8 秒
- 任一秒內大面積明暗變化 ≤ 3 次

## 6. 檢查與交付
- 動工前：給我一張節拍圖（每句落在哪個小節哪一拍）和 4 張關鍵靜態圖（第一幀、副歌拍點、最擠的一句、最後一幀）
- 縮到 360 px 寬看一次，字還讀得出來
- studio qa 沒有 FAIL；交付 MP4、封面（第一幀）、SRT

## 7. 開始方式
先問我最多 3 個問題（每題附建議），然後切片段、對歌詞、給我節拍圖與 4 張靜態圖，我同意後再做動態。
```

## 寫的時候注意

- 短片的「設計」大多在靜態圖階段就決定了。4 張關鍵靜態圖不滿意，不要進動態。
- 一段 15–25 秒只鎖 1–3 個重音；其他字的進場可以在 ±0.1 秒內往重音靠，但可讀性優先。
- 直式不是把橫式裁切：版面從 `film.width`／`film.height` 算，字級跟著畫面寬度走。
