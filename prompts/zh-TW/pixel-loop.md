# 像素循環動畫簡報

> 適合：可以無限循環的像素動畫（頭像、桌布、直播待機畫面、歌曲的視覺化循環）。
> 用法：〔〕換成你的內容。像素藝術的關鍵是**限制**：邏輯解析度、色盤、整數座標、量化的姿勢。
> 背景：[docs/07 風格：像素藝術的規格](../../docs/07-style.md#像素藝術的規格)、風格卡 [styles/pixel-crt](../../styles/pixel-crt/STYLE.md)。

```markdown
# 像素循環動畫簡報

## 1. 角色與標準
你是像素畫師與動畫工程師。標準：〔像經典遊戲的過場：每個像素都有理由，循環接縫完全看不出來〕。
照 studio 技能的流程做（短片：G2 與 G3 可以合併）。

## 2. 素材
- 主題：〔一個場景與一個動作，例：雨夜窗邊打瞌睡的貓〕
- 音樂：〔沒有／audio/〔檔名〕，權利：〔…〕，循環長度要等於整數小節〕
- 參考：refs/〔…〕（學它的色盤與輪廓，不要描它）

## 3. 方向
- 色盤：固定〔24〕色，每個像素都來自這個色盤（hex 列在 TREATMENT.md）
- 不要：漸層、反鋸齒、陰影模糊、旋轉、半像素位置、非整數縮放

## 4. 結構
- 邏輯解析度〔160×90〕，整數倍放大到〔1920×1080〕（×12），關閉平滑
- 循環長度〔4〕秒（有音樂時＝〔2〕小節）；最後一幀接回第一幀
- 一個主要動作＋2–3 個背景循環（雨、燈、尾巴），各自的週期是總長的因數

## 5. 製作規則
- 先畫在小畫布上，再整數倍放大；ctx.imageSmoothingEnabled = false；座標取整數
- 姿勢參數平滑變化，但每幀量化到像素網格；在 30 fps 裡讀起來像 8–12 fps 的精靈動畫
- 擠壓伸展只能以整像素為單位
- 所有運動是 t 除以循環長度的週期函式：f(t) = f(t + 循環長度)
- 中文像素字：先畫在小畫布上，以 0.5 透明度門檻二值化；邏輯尺寸至少 18 px；字越小字重越輕（18 px 用 400，34 px 標題用 500–700）
- 畫面是 t 的純函式；隨機一律用 rng(seed) 或 hash

## 6. 檢查與交付
- 接縫檢查：渲染最後一幀與第一幀並排；studio verify 通過
- 放大看 4 張靜態圖：每個像素都在格子上、都來自色盤（有 CRT 或掃描線效果時，關掉效果再算一張來檢查）
- 會被縮小播放的版本（手機、GIF）：每條掃描線至少 3 列像素，不然會出現摩爾紋
- 交付：MP4（循環 3 次）、〔GIF 或 WebP 循環檔〕、封面

## 7. 開始方式
先問我最多 3 個問題（每題附建議），然後給我色盤和一張靜態圖，我同意後再做動態。
```

## 寫的時候注意

- 在高解析度畫布上「畫得像像素」和真的像素藝術差很多：一定要先畫小再放大。
- AI 生成的像素圖要重新對齊到真正的像素網格，並換成你的色盤。
- 循環的每個子循環週期都要能整除總長，不然接縫會跳。
