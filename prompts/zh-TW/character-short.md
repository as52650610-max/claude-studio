# 角色短片簡報

> 適合：30 秒–2 分鐘、有一個會演戲的角色的短片或 MV（剪紙骨架、扁平插畫、像素角色）。
> 用法：〔〕換成你的內容。角色動畫是程式路線公認的弱點：時間要花在**角色設定**與**骨架**上，不是特效。
> 背景：[docs/07 風格：角色](../../docs/07-style.md#角色)、[docs/08 動態](../../docs/08-motion.md)。

```markdown
# 角色短片簡報

## 1. 角色與標準
你是角色設計師、動畫師、導演與工程師。標準：〔角色一出場就讓人記住；表演讀得懂，不像貼紙在滑〕。
照 studio 技能的流程做；角色定案前不做任何鏡頭。

## 2. 素材
- 角色參考：refs/〔角色圖〕（權利：〔我畫的／委託／官方允許二創，規範見〔網址〕〕）
- 歌曲或配樂：audio/〔檔名〕，權利：〔…〕；或〔沒有音樂，用環境音〕
- 故事一句話：〔一個主角、一個目標、一個轉折〕

## 3. 方向
- 角色個性：〔…〕；招牌動作：〔…〕
- 風格：〔styles/ 的風格卡，例：paper-cutout〕
- 不要：角色每鏡長得不一樣、原地晃動、沒有預備動作的動作、滿屏特效蓋過表演

## 4. 結構
- 前 3 秒是鉤子；首尾呼應；情緒高點用只有這個媒材做得到的動作
- 一個看縮圖也讀得懂的笑點，勝過三個讀不懂的
- 道具升級：開場介紹一個道具，中段誤用它，在高潮變形，結尾回收
- 長度：〔45 秒〕；〔16:9 1920×1080〕；〔30〕fps

## 5. 製作規則
- **角色聖經**（docs/character_bible.md）：把參考圖詳細寫回文字；用程式從參考圖取樣色票；寫一條「換風格也不能變」的身分規則（例：右眼下的痣、紅圍巾）
- **設定表**：正面／側面／背面、3–4 種表情、2–3 個關鍵姿勢、色票；和參考圖並排，直到我說「對，就是他」
- **骨架**：根 → 底盤 → 軀幹 → 脖子 → 頭；可替換的手勢；程序化臉部（眼瞼、瞳孔、高光、3–4 幀眨眼）；次要動作用彈簧，從 0 算到 t
- **表演一拍一拍規劃**：看 → 伸手 → 抓住 → 拿起 → 遞出 → 放開；預備、動作、跟隨；不要在 if 裡直接切換姿勢
- 角色一拍二（stepTime 12 fps），鏡頭與光每幀都平滑
- 時間從歌曲或 cues.json 來；畫面是 t 的純函式

## 6. 檢查與交付
- 每一鏡至少三輪自評：渲染逐幀條，看手、腳、臉有沒有跳（一幀移動超過 12 px 就是跳）
- 和設定表並排比對：角色有沒有走樣
- studio qa 沒有 FAIL；studio-jury ≥ 8
- 交付：MP4、封面、角色聖經與設定表、CREDITS.md、REPRODUCE.md

## 7. 開始方式
先問我最多 4 個問題（每題附建議）。第一個交付是角色設定表，不是動畫。
```

## 寫的時候注意

- 角色定案之後改角色只要改一張圖；之後才改，每一鏡都要重做。所以設定表這一關要你親自點頭。
- 肩膀的旋轉順序是先外展再屈曲，反過來舉起的手會交叉成 X；手臂與軀幹重疊處不要描邊，會露出紙偶接縫。
- 手持的東西要真的在兩掌之間；滾動的東西依距離 ÷ 半徑轉動。
- 用影片模型做角色時改用 [hybrid-mv.md](hybrid-mv.md)：模型只動綠幕上的一個角色，世界由程式畫。
