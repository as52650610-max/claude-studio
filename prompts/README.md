# 導演簡報範本 · Director briefs

複製一份，把〔〕換成你的內容，在專案資料夾裡貼給 Claude Code。沒有咒語：真正有用的是素材、寫在最上面的品質標準、
先看靜態圖再做動態的關卡，以及禁用清單（見 [docs/12](../docs/12-prompts.md)）。

Copy one, replace the [brackets], and paste it into Claude Code started in the project folder. There
are no magic words: what works is assets, a quality bar stated at the top, gates (stills before
motion) and a ban list ([PLAYBOOK §16](../docs/en/PLAYBOOK.md)).
