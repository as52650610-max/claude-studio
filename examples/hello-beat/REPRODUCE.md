> G7 重現文件。照這份做，另一個代理（或你）能從零做出同一支片；用這個資料夾重做只要兩行指令。

## 用這個資料夾重做（Rebuild from this folder）

歌不進版控，同一個 seed 會生成同一首歌、同一份真值。在 repo 根目錄：

```bash
node tools/studio.mjs music examples/hello-beat/audio/song.wav --plan-file examples/hello-beat/music.json --seed 7 --truth examples/hello-beat/data/song.truth.json --stems examples/hello-beat/audio/stems
```

```bash
node tools/studio.mjs deliver examples/hello-beat
```

應該得到：810 格；`qa/report.md` 0 FAIL、0 WARN；唯一的切點（0:12.50）離拍 −0.2 格；AAC 編碼後 −14.1 LUFS、−1.54 dBTP。

## 技術路線（Technique）

- 全部是 Canvas 2D 程式，一個檔案：[`shots/beat.js`](shots/beat.js)。四個疊在一起的鏡頭：`dot`（點）、`chorus`（副歌）、`end`（句點）、`hud`（儀表與時間軸），
  整片再加 3.5% 顆粒（`post`）。
- 時間來自 `data/songmap.json`（拍、停頓、重擊、分軌分析出的大鼓與小鼓）和小節格線 `song.T`。小鼓滾奏的 20 下照 `music.py` 演奏的格線寫：
  第 5 小節八分音符、第 6 小節十六分音符到停頓。
- 段落名稱（`PARTS`）照 `music.json` 的小節寫：分析把 12 小節併成了 3 段。

## 色彩與字型（Palette and type）

| 紙 | `#F2EFE8` | 背景 |

Noto Sans TC（SIL OFL 1.1）：標題 700、副歌 900、計數 200。`studio fonts` 子集化，授權 `fonts/OFL.txt` 放在旁邊。

## 動態（Motion）

- 落下用重力（quadIn），落地用彈簧壓扁再回彈（`spring`，freq 22、damp 0.3）。
- 每個大鼓讓點脹大 20%，半衰期 0.09 秒（`song.hit('kick', t, 0.09)`）；每個小鼓從點彈出一圈波紋。
- 只有兩種轉場：點爆開成整個畫面（0.32 秒，ease.out）、畫面收回成點（0.45 秒，ease.inOut）。

## 遇過的坑（Pitfalls met）

| 坑 | 怎麼解決 |
|---|---|
| 分析把 12 小節併成 3 段（短於 4 小節的段落會被合併） | 段落名稱用 `music.json` 的小節，時間仍來自量到的拍子 |
| 從整首混音分析，小鼓常被當成大鼓（多 9 個假大鼓、36 個假小鼓） | 用分軌分析（`--stems`）：大鼓 30/32、小鼓 20/32，沒有假的 |
| 0:24.90 點飛向句點時擦過「beat」的 t | 分兩段：先跳到句點上方，再用開場同樣的 0.3 秒落下；字在落地後才出現 |
| 0:20.75 收回時，強調色用時間判斷，紙色三角形畫在紙上看不見 | 強調色改看那一點底下是不是紅色（`m.red(t)`） |
| 0:24.70 歌結束後標籤顯示「預備 count-in」、計數 12.5 | 標籤沿用最後一段；引擎修正 `song.position` 在最後一小節之後的算法（並加測試） |
| 鐘聲尾巴超出片尾 | 鐘聲改 1.4 秒 |

## 從零開始：交給 Claude 的提示（From nothing: the prompts）

> 用 studio skill 在 projects/hello-beat 做一支 27 秒的片，全自動模式。一句話：這首歌是一個點，旁邊的儀表說明它為什麼動。
> 音樂用 studio music 生成：120 BPM、D 小調，前奏 2、主歌 2、導歌 2（小鼓滾奏、停頓）、副歌 4（重擊）、尾奏 2 小節，seed 7，寫出真值和分軌。
> 紙、墨、一個朱紅；Noto Sans TC。點落在第 1 小節、跟著大鼓脈動、滾奏時蓄力、停頓時只剩外框、重擊時爆開成紅色、最後落下成為句點。
> 每個音效都要有理由；重擊交給音樂。時間只來自 songmap，不寫死秒數。

之後每一關照 skill 走：分析和真值對答案（G1）、三個結構候選（G2）、分鏡表（G3）、全片（G4–G5）、`studio qa` 與修正（G6）、交片（G7）。
