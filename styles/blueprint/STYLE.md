# 藍圖 · Blueprint

> **In short.** A technical drawing on blueprint paper. White lines in two widths, faint construction under them, and one orange that only ever means "measured". Nothing fades in. A pen draws every line, in the order a drafter works: construction first, then the object over it, then dimensions, hatching, a detail view and, last, the title block. The demo is 8 seconds on a 120 BPM grid, and it draws sound. Bar 1 draws the border and a circle divided into twelve, projected across one beat. In bar 2 a pen draws a sine wave, one period per beat, and dimensions each beat as it finishes: 0.50 s. Bar 3 dimensions the bar, hatches the wave as a cut solid, labels the compressions and rarefactions, and calls out a detail. Bar 4 draws the detail at 2:1, where a sixteenth measures 0.125 s, and fills in the title block.

## 1. 本質 Essence

- **一張圖紙。** 畫面是一張紙，不是一個空間：沒有景深、沒有透視、沒有光源。紙的四周有圖框和分區編號，右下角有標題欄。
- **只有線和字。** 物體用粗線，其他的（尺寸、引線、剖面線、中心線）用細線，兩種寬度是 2 比 1。構造線也是細線，只是淡（35%）。面積只能用剖面線表示，不能填色。
- **橘色有一個意思。** 橘色只用在量出來的數字上，也就是尺寸的數值。它不是裝飾色，它說的是「這個數字是量的」。
- **照製圖的順序畫。** 先畫淡的構造線，再在上面描粗的物體線，然後標尺寸、畫剖面線、畫細部圖，最後填標題欄。觀眾看到的是這張圖怎麼被畫出來。
- **筆畫出來，不是浮出來。** 線從一端長到另一端，圓從圓規的起點轉一圈，字一個一個寫上去。沒有東西淡入，畫好的線也不再動。
- **數字是真的。** 圖上的尺寸要量得出來：示範的 0.50 s 是從歌曲的拍點算出來的，不是寫死的字。

它不是：

- 不是科幻電影的全息介面（HUD）。沒有發光、沒有掃描線、沒有半透明的藍色面板、沒有轉動的雷達。那是螢幕，這裡是紙。
- 不是「藍底白線」的濾鏡。把照片轉成藍白的線稿，沒有構造線、尺寸、剖面線和標題欄，只是顏色像。
- 不是 3D 線框。這裡只有正投影：前視、側視、細部，畫面不轉。
- 不是資訊圖表。沒有圖示、沒有圓角卡片、沒有巨大的數字。

### 禁用清單 Ban list

- 發光、光暈、陰影。藍圖是曬出來的，線不會發光。
- 淡入淡出。線要畫出來，字要寫出來。
- 第三種線寬，或第二個強調色。
- 把橘色用在量測值以外的地方：標題、裝飾、強調、選取。
- 漸層填色、半透明的色塊。
- 斜體或粗體。字一律用 500，英文全部大寫、字距 0.12 em。
- 沒有構造線就冒出來的曲線。
- 字壓在線上。字周圍的線和剖面線要斷開（見第 4 節）。
- 旋轉、推拉、手持晃動的鏡頭。

## 2. 材料與渲染 Material

真實的媒材有兩個。一個是藍圖本身：1842 年 John Herschel 發明的氰版印刷（cyanotype）。原圖畫在半透明的描圖紙上，疊在塗了感光劑的紙上曝光；照到光的地方變成普魯士藍，被線擋住的地方留下紙的白。所以藍圖是藍底白線，而且紙的藍色不太均勻。另一個是工程製圖的規矩：線分粗細，構造線先畫，尺寸、剖面線、細部圖、圖框和標題欄都有固定的畫法（ISO 128 管線型和剖面，ISO 129 管尺寸，ISO 5457 管圖紙和圖框，ISO 7200 管標題欄）。程式的對應做法都在 [`demo/shots/blueprint.js`](demo/shots/blueprint.js)。

- **紙（`paper`）。** 由上而下從 `#12355B` 漸層到 `#0E2A47`。曝光不均：用 240 × 135 的分形雜訊放大成淡淡的雲斑，亮處偏青、暗處偏墨。5,000 個灰塵斑點。對折過兩次：每道摺痕是一條亮線，一側有陰影。圖框裡有方格，每 24 px 一格，每 5 格一條較亮的線。最後加暗角。這些都在載入時畫好，每一格只做一次 `drawImage`。
- **筆（`pen()`）。** 粗線 3.2 px 畫物體，細線 1.6 px 畫其他東西，比例 2 比 1（ISO 128 的 0.7 mm 和 0.35 mm）。構造線是 35% 不透明的細線。中心線和軸是鏈線 `[32, 6, 6, 6]`。線頭和轉角都是圓的，像針筆畫的。
- **畫線（`path`、`trace`）。** 先量好一條折線的長度，每一格畫到總長的 u 為止：筆停在哪裡，線就停在哪裡。圓（`compass()`，從起點轉 u 圈）和正弦也用同一個原則。不用虛線偏移（dash offset），所以鏈線的花紋固定在起點，不會跟著筆跑。
- **寫字（`letter`）。** 一個字一個字寫上去。置中或靠右的字，先量好整行的寬度，每個字直接落在整行寫完時的位置。
- **尺寸（`dimension`）。** 尺寸界線離物體 8 px，超出尺寸線 10 px。尺寸線從中間往兩邊長出來，碰到界線時箭頭落下（實心，夾角 30°，長 16 px），數值用橘色寫在線的上方 9 px。
- **剖面線（`hatch`）。** 給它一個判斷「點在不在裡面」的函式和一個方向，它沿著每條線每 0.5 px 檢查一次，得到裁好的線段。間距 12 px。同方向的線在相鄰的區域會對齊。
- **斷線（`knock()`）。** 寫字之前，先從紙的畫布複製同一塊貼回去，字周圍的線和剖面線就斷開了，和真的圖一樣。
- **細部圖。** 同一個幾何用 2 倍的座標重新畫一次，但線寬和剖面線間距不放大，用的是同一支筆。
- **示範的構造。** 以振幅為半徑畫一個圓，分成十二等分；一拍的長度也分成十二等分，各畫一條垂直線；從圓上第 k 個分點拉水平線到第 k 條垂直線，交點就是正弦上的點。這是製圖課本畫正弦曲線的方法。一拍是 12 格（288 px），振幅是 6 格。

## 3. 色彩邏輯 Colour

| 角色 | 色值 | 規則 |
|---|---|---|
| 紙（上） | `#12355B` | 由上往下漸層到下一色 |
| 紙（下） | `#0E2A47` | 也是 `studio.json` 的背景色 |
| 線 Line | `#E8F1FF` | 所有的線和字。偏藍的白，不是純白 |
| 量測值 Value | `#FF8A3D` | 只用在尺寸的數值 |

亮度分成四層，越重要越亮。對比是在紙的上緣和下緣量的：

| 層 | 做法 | 對比 |
|---|---|---|
| 物體、字、尺寸線 | `#E8F1FF` | 10.95 / 12.81 |
| 量測值 | `#FF8A3D` | 5.31 / 6.21（超過一般文字的 4.5） |
| 構造線 | `#E8F1FF`，35% | 2.69 / 2.85 |
| 方格 | `#E8F1FF`，12% 與 6% | 1.41 與 1.17 |

- **白是「畫的」，橘是「量的」。** 標題、歌名、強調都不用橘色。要強調，就用粗線、引線或細部圖。
- **面積不填色。** 要表示「這是一塊實心的東西」，就畫剖面線；兩塊不同的東西，剖面線的方向就不同（示範的密部 45°、疏部 135°）。

## 4. 字型與字幕 Type

- **一種字型、一種字重。** Noto Sans TC 500（SIL OFL 1.1）。英文全部大寫，字距 0.12 em；中文不加字距。工程字（ISO 3098）就是這種感覺：筆畫粗細一致、沒有裝飾。
- **大小：**

  | 用在 | 大小 |
  |---|---|
  | 圖名 | 40 px |
  | 尺寸的數值 | 24 px |
  | 註記 | 中文 24 px，英文 16 px |
  | 分區編號 | 18 px |
  | 細部圖的標籤 | 中文 20 px，英文 14 px |
  | 標題欄的值 | 22 px |
  | 標題欄的欄名 | 12 px |

- **字周圍的線要斷開。** 製圖的慣例是：字放在剖面線裡時，剖面線要在字的周圍斷開。示範的 0.125 s 和細部圓旁的 A 都是先貼回一塊紙再寫字。
- **單位。** 真的工程圖不在尺寸上寫單位，單位寫在標題欄（「單位 秒」）。示範還是寫了「s」，因為時間不是製圖的預設單位，觀眾也不是工程師。
- **逐字寫出。** 中文每秒 24–30 個字，英文標籤每秒 40–60 個字。數值的第一個字落在拍點上。
- **歌詞放哪裡。** 當作引線註記（一句一條引線，指向它說的東西），或寫在圖框裡的「註」欄，一行一句，逐字寫出。
- 改了文字之後，執行 `node tools/studio.mjs fonts styles/blueprint/demo` 重新子集化字型。

## 5. 動態質感 Motion

- **筆的速度。** 每一種東西有自己的畫法和時間：

  | 東西 | 怎麼畫 | 時間 |
  |---|---|---|
  | 圖框 | 兩筆，從左上角到右下角 | 0.45 秒，`quadInOut` |
  | 中心線、軸 | 從一端到另一端 | 0.3–0.4 秒，`sineInOut` |
  | 圓 | 圓規轉一圈 | 0.35 秒（細部圓 0.12 秒） |
  | 構造線 | 一條接一條，間隔 0.025 秒 | 每條 0.12 秒 |
  | 物體線（正弦） | x 跟著拍子等速前進 | 一拍一個週期 |
  | 尺寸 | 界線 → 尺寸線 → 箭頭 → 數值 | 界線、尺寸線各 0.1 秒 |
  | 剖面線 | 從左掃到右，一條接一條 | 全部 0.36 秒，每條 0.06 秒 |
  | 字 | 一個字一個字 | 每秒 24–60 個字 |

- **筆尖就是播放頭。** 正弦的 x 用 `song.beatAt(t)` 換算：筆每到一個拍點，正好畫完一個週期。換成速度會漂移的真實歌曲，筆還是落在真正的拍點上。
- **數值落在拍點上。** 線在拍點之前畫好，數值的第一個字寫在拍點上。
- **畫好就不動。** 沒有呼吸、沒有漂浮、沒有抖動。整張圖唯一在動的地方是筆尖。
- **構造線不擦掉。** 它們留在圖上，淡淡的，說明曲線是怎麼來的。

## 6. 鏡頭語法 Camera

| 動作 | 表達 | 用在 |
|---|---|---|
| 鎖定 | 一張圖紙 | 全片 |
| 細部圖（同一張紙上的放大圖） | 聚焦、放大一個瞬間 | 副歌前、重要的一個字 |
| 換一張圖紙（SHEET 1/3 → 2/3） | 換段、換一個主題 | 段落轉換 |
| 沿著一張很長的圖平移 | 時間過去、沿著時間軸讀 | 主歌 |

- 放大用細部圖，不推鏡頭：細部圖是製圖本來就有的東西，而且線寬不會變粗。
- 平移不貴。整張紙一起移動，編碼器用動態補償就預測得到：把示範整張以每秒 30 px 平移是 1.5 MB，每秒 200 px 是 1.4 MB，和鎖定時（1.4 MB）差不多。貴的是每一格都換的雜訊（見第 10 節）。
- 禁止：旋轉、透視、景深、手持晃動。

## 7. 聲音調色盤 Sound

- **音色：** 針筆和鉛筆在紙上的摩擦、尺和圓規碰到桌面、翻動圖紙，加上節拍器和純正弦波。
- **音樂：** 極簡主義的重複、minimal techno、IDM、鋼琴的分解和弦；90–130 BPM。這個風格的主題是「準」，所以拍子要清楚。
- **靜默：** 細部圖畫出來之前停一拍，只留節拍器。
- 用 `studio sfx` 的配方近似（建議值，示範本身沒有聲音）：

  | 畫面 | 配方 | cue 設定 |
  |---|---|---|
  | 圖框 | `whoosh`（`params: { dur: 0.45, bright: 0.1 }`） | `gain: -18` |
  | 一條構造線 | `tick` | `gain: -24` |
  | 圓規轉一圈 | `whoosh`（`params: { dur: 0.35, pitch: -5, bright: 0.05 }`） | `gain: -20` |
  | 筆經過拍點 | `beep`（`params: { dur: 0.08, pitch: 0, glide: 0 }`），小節第一拍 `pitch: 12` | `gain: -16` |
  | 尺寸的箭頭落下 | `click`（`params: { pitch: 5 }`） | `gain: -14` |
  | 數值寫出 | `typing` | `gain: -20` |
  | 剖面線 | `tick`，每個區塊一下 | `gain: -24` |
  | 細部圓 | `pop`（`params: { pitch: -3 }`） | `gain: -14` |
  | 細部圖的數值 | `bell`（`params: { note: 81 }`） | `gain: -12` |
  | 標題欄的一列 | `step`（`params: { pitch: -4 }`） | `gain: -14` |

## 8. 原生招式 Native moves

| 招式 | 做法 | 適合的內容 |
|---|---|---|
| **構造線先行** | 先畫淡的構造線（圓、等分、輔助線），再用粗線描出物體 | 開場、建立主題、副歌前的蓄力 |
| **投影** | 從一個圖形拉水平線或垂直線，得到另一個圖形（圓變成正弦） | 轉化、因果、「A 變成 B」 |
| **尺寸標註** | 界線、尺寸線長出來，箭頭落下，數值寫在拍點上 | 節拍、倒數、一個重要的數字（年份、距離、心跳） |
| **剖面線** | 把一塊面積「切開」，用斜線填滿；不同的部分用不同的方向 | 重拍、重量、對比的兩件事 |
| **引線註記** | 一個點、一條引線、一段字 | 歌詞、角色介紹、說明 |
| **細部放大** | 在圖上圈一個圓、標一個字母，在旁邊用 2:1 再畫一次 | 聚焦、放大一個瞬間、副歌 |
| **圖框標題欄** | 填上圖名、速度、圖號、張數 | 歌名、歌手、工作人員名單、結尾 |
| **換圖紙** | 一張畫完，下一張（SHEET 2/3）從旁邊滑進來蓋上 | 換段、換場 |

## 9. 媒材的陷阱 Pitfalls

| 症狀 | 原因 | 對策 |
|---|---|---|
| 細部圖的線浮在外框外面 | 外框用一筆從上面轉一圈，框裡的構造線在圓還沒畫完時就出現了 | 外框從引線落點分兩筆畫，在底部會合；框畫到八成，裡面的線才開始 |
| 細部圖的數值壓在曲線上，曲線還穿過箭頭 | 曲線離開拍點時很陡（72°）。尺寸線放得越低，曲線和它的交點越靠近左邊的箭頭；數值放在中央，又剛好被曲線穿過 | 先算交點在哪裡：尺寸線放在拍點上方 104 px（2:1 的圖上），交點離箭頭的尾端 18 px；數值移到曲線右邊 |
| 字壓在剖面線上 | 剖面線填滿了整塊面積 | 寫字前把那一塊紙貼回去（`knock()`），剖面線在字的周圍斷開 |
| 置中的字邊寫邊往左滑 | 每多寫一個字，就用目前的寬度重新置中 | 先量整行的寬度，每個字落在整行寫完時的位置（`letter()`） |
| 鏈線的花紋跟著筆跑 | 用虛線偏移做畫線的效果 | 用折線截斷來畫（`trace()`），花紋固定在起點 |
| 細部圖的線變粗、剖面線變疏 | 把畫面直接放大兩倍，線寬和間距也跟著放大 | 細部圖重新畫：座標乘 2，線寬和剖面線間距不變 |
| 紙看起來像星雲 | 曝光不均的雲斑太強（亮 70、暗 110） | 降到亮 45、暗 75。雲斑只是讓紙「不平」，不能變成圖案 |
| 摺痕看不見 | 亮線 8%、陰影 12%、寬 10 px，縮小播放就消失 | 亮線 16%、陰影 22%、寬 16 px：看得出來，但不會被當成一條線 |
| 字變成方塊 | 字型子集裡沒有新字 | 改字後執行 `studio fonts` |

## 10. 引擎 Engine

[`demo/shots/blueprint.js`](demo/shots/blueprint.js) 匯出這些函式和常數：

| 名稱 | 作用 |
|---|---|
| `PALETTE`、`PEN` | 四個顏色；兩種線寬和構造線的不透明度 |
| `paper(W, H)` | 藍圖紙：漸層、雲斑、斑點、摺痕、方格、暗角，畫在一張畫布上 |
| `path(points)`、`trace(g, path, u)` | 量好長度的折線；畫到總長的 u 為止 |
| `letter(g, text, x, y, t, t0, { size, spacing, fill, align, rate })` | 逐字寫出，字落在最後的位置 |
| `dimension(g, x1, x2, y, value, t, t0, { cx, size })` | 水平尺寸：尺寸線、箭頭、橘色的數值 |
| `hatch(inside, box, dir, gap)` | 剖面線：裁好的線段 |
| `blueprint` | 示範的鏡頭 |

`pen()`、`compass()` 和 `knock()`（字周圍斷線）沒有匯出，複製這個檔案時一起帶走。

- **速度：** 每格繪製 14–21 ms：紙只是一次 `drawImage`，其餘是幾百條線和幾十個字。8 秒示範以 1080p 算圖每秒 23–27 格（RTX 3090 Ti），載入約 0.4 秒（紙和剖面線）。
- **位元幾乎不花：** 檔案 1.4 MB。紙和畫好的線都不動，每一格只有筆尖附近在變。六張風格卡裡只有[瑞士動態排版](../swiss-kinetic/STYLE.md)更小（0.53 MB）；[Riso 印刷](../riso-print/STYLE.md)的顆粒每格都換，是 14.6 MB。
- **數字是算出來的：** 尺寸的數值是 `song.T()` 兩個拍點的時間差，速度是 `song.bpm`。換一首歌，數字會跟著變。
- **可重現：** `draw()` 裡沒有隨機數。紙在載入時用 `rng('blueprint')` 和 `fbm2` 畫好，剖面線也在載入時算好。`studio verify` 的 18 幀全部相同。

## 11. 變化空間 Variations

以下都和示範（一張圖紙上構造、畫出、標註、剖開、放大一個正弦波，最後填標題欄）差很遠。

**結構**

1. **一首歌的設計圖：** 每一段是一張圖紙（SHEET 1/4 到 4/4）。前奏畫構造，主歌畫三視圖，副歌畫剖面圖，尾奏畫爆炸圖，所有零件拆開、編號。
2. **專利圖：** 一個虛構的發明，例如「把心事收好的盒子」。零件編號 1、2、3 對應歌詞，每一段是一張 FIG.
3. **建築平面圖：** 一間房子的平面圖，每個房間的註記是一句歌詞；換段就換一層樓的圖紙。

**開場**

1. 示範的做法：圖框分兩筆畫上，構造線先行。
2. 一張空白圖紙，先填好標題欄的歌名和歌手，第一拍才開始畫。
3. 從一個點開始：圓規的針腳落在紙上，第一個圓就是第一拍。

**結尾**

1. 示範的做法：填完標題欄，最後寫上張數 1/1。
2. 構造線一條一條擦掉，只剩乾淨的物體線。或者反過來，物體線擦掉，只剩構造線，像一張沒畫完的圖。
3. 新的一張描圖紙蓋上來，上面只有一條線：下一首歌的第一筆。
