# 水墨紙本 · Ink and Paper

> **In short.** Warm black ink on rice paper. Each stroke lands on a beat, and washes soak out from it afterwards. Bare paper is the loudest thing in the frame, and one red seal is the full stop. Everything is drawn in code (Canvas 2D); nothing is generated. The demo is 8 seconds on a 120 BPM grid: one ridge stroke, two washes, moss dots, ripples, two columns of text and a seal.

| 拍點 | 發生什麼 |
|---|---|
| 1.1 → 1.4 之後 0.3 秒 | 一筆畫完山脊（勾），後半段筆乾成飛白 |
| 1.3 → 2.2 | 近山的淡墨從山脊往下滲（染） |
| 2.1 → 2.4 | 遠山的清墨滲開，底部化成霧 |
| 2.1、2.1.3、2.2、2.2.3 | 四組苔點落在八分音符上（點） |
| 2.3、2.3.3、2.4 | 三道水紋，各 0.3 秒 |
| 3.1、3.3 | 「山在」「水在」由上往下寫入，各 0.6 秒 |
| 4.1 | 印章在 0.12 秒內落下，3 px 震動 |
| 整段 | 鏡頭從 1.00 推到 1.03 |

## 1. 本質 Essence

- **一筆就是一個事件。** 筆落下、行筆、提起，三個時刻都對在音樂上。
- **留白比墨多。** 紙是最大的元素，畫面至少六成是空的紙。
- **墨分五色。** 只有一種墨，靠濃淡做出遠近和層次。
- **畫好之後還在變。** 墨會暈開，渲染會往下滲，像殘響。
- **紅色只有一處**，就是印章。

它不是：

- 不是「中國風」素材包。祥雲、燈籠、金邊、龍鳳都不是水墨。
- 不是水彩。水彩靠彩色透明疊色，水墨是單色，靠濃淡。
- 不是書法字型動畫。字是畫的一部分，不是標題卡。
- 不是「墨滴入水」的煙霧粒子素材。

### 禁用清單 Ban list

- 純黑 `#000` 和純白。墨是暖黑 `rgb(26,23,20)`，紙是 `#F3EEE2`。
- 墨滴入水的煙霧、粒子散開成字。
- 金色、漸層背景、光暈、鏡頭光斑、發光。
- 祥雲、燈籠、龍、鳳、扇子等符號堆疊。
- 粗細固定的向量線。
- 全部元素同時淡入，或兩張畫交叉溶解。
- 彈跳、overshoot、旋轉、3D 翻轉。
- 用字型冒充手寫的毛筆字，或生成的假漢字。
- 一幀出現兩個以上的印章，或印章離開落款的位置。

## 2. 材料與渲染 Material

真實的媒材是宣紙（吸水、有纖維）、墨（煙灰加膠）、毛筆和朱砂印泥。程式的對應做法都在 [`demo/shots/ink.js`](demo/shots/ink.js)。

- **紙。** 底色上疊一層低頻斑駁（240×135 的 fbm 放大到全畫面，不透明度 0.35），再加 2,600 根短纖維。
- **筆畫（`brushStroke`）。** 每一筆在載入時先畫在離屏畫布上，共六層：
  1. **筆身**是一條隨壓力變寬的緞帶，兩側邊緣各自帶雜訊，模擬毛的邊緣。
  2. **墨暈**：筆身放寬 25%、模糊 3 px、濃度 30%。乾筆的段落沒有暈。
  3. **飛白**：14 根「毛」各有自己乾掉的門檻。墨不夠時，那根毛沿著筆路刮出紙白；越乾，縫越寬。濕的段落縫一律關著。
  4. **乾擦**：最乾的地方再加上沿筆路方向的短刮痕，是紙的齒。
  5. **墨少就淡**：乾的段落整體變淡，最多 25%。
  6. **纖維**：紙的纖維淡淡透過墨。
- **揭開（`reveal`）。** 沿筆路排一串圓盤當遮罩，每幀多露出一段。圓盤在筆尖處收窄：筆尖在前，墨在後面散開。
- **渲染（`wash`）。** 以四分之一解析度逐像素計算，最濃在山脊、往下淡出。兩層 fbm 做出濕中濕的不均勻，`mist` 讓遠山在近山上方化成霧。
- **滲開（`soak`）。** 渲染從山脊往下滲，前緣不齊。遮罩用二分之一解析度，因為渲染本來就沒有硬邊。
- **印章（`seal`）。** 白文印：字從紅色裡刻掉，加上磨損斑點，用 `multiply` 疊在紙上。

## 3. 色彩邏輯 Colour

- **單色。** 所有東西都是同一個暖黑，只改不透明度。
- **墨分五色**，示範裡的對應：

  | 墨色 | 不透明度 | 用在 |
  |---|---|---|
  | 焦 | 0.92 以上 | 苔點、字 |
  | 濃 | 0.9 | 主筆（山脊） |
  | 重 | 0.6 | 水紋 |
  | 淡 | 0.26 | 近山渲染 |
  | 清 | 0.18 | 遠山渲染 |

- **近濃遠淡。** 越遠越淡、越模糊、越沒有輪廓。遠山不勾線（沒骨）。
- **紅只給印章。** 朱砂 `#C8352B`，面積在 2% 以下，一幀最多一個。
- **紙不是白。** 高光就是留白，不另外畫亮色。

| 角色 | 色值 |
|---|---|
| 紙 | `#F3EEE2` |
| 墨 | `rgb(26,23,20)`，只改 alpha |
| 紙斑與纖維 | `rgb(120,100,70)`、`#8a7a60`、`#ffffff`，alpha 0.05–0.13 |
| 印 | `#C8352B` |

## 4. 字型與字幕 Type

- **Noto Serif TC**（SIL OFL 1.1），直排，由右往左。正文 600 字重，下面墊一層模糊 1.6 px、濃度 0.35 的同一行字，做出滲進纖維的感覺。
- 字級（1080p）：題字 96 px，歌詞 40–56 px。
- **字幕屬於這個世界。** 直排在留白處，以墨色由上往下寫入。不要白字加黑框。
- 歌詞一句一欄，一欄最多七個字，換句落在拍點上。
- 直排時拉丁字母由 `verticalText` 轉 90°。英文副題用 Serif 300、字距 0.1 em，橫排小字放在欄底。
- 印章字用 Serif 900。
- OFL 授權的手寫書法字型很少，所以**不要假裝手寫**。真的需要手寫，就寫在紙上掃描成 PNG 或 SVG，並列入 CREDITS。
- 改了文字之後，執行 `node tools/studio.mjs fonts styles/ink-and-paper/demo` 重新子集化字型，否則新字會變成方塊。

## 5. 動態質感 Motion

- 30 fps，筆的運動每幀平滑，因為筆是連續的。除了筆、滲開和印章，畫面上**沒有東西在動**。
- 一筆的長度：主筆 1–4 拍；短筆半拍；點是瞬間，落下後 0.08 秒內從 0.8 倍散開到 1 倍。
- 行筆用 `ease.inOut`：起筆壓、行筆快、收筆慢。
- **落點在拍上。** 起筆對小節第一拍，點落在八分音符，印章落在小節第一拍。
- **暈和滲是拍後的動作。** 落筆後 1–3 拍內用 `ease.out` 滲開，像殘響。
- 印章：0.12 秒內從 1.3 倍縮到 1 倍（`ease.quadIn`），落下時震動 3 px、半衰期 0.05 秒。
- 永遠不動：紙，以及已經乾的筆畫。不呼吸、不閃爍。
- 不用彈跳、overshoot、旋轉、循環晃動。

## 6. 鏡頭語法 Camera

| 運鏡 | 表達 | 用在 |
|---|---|---|
| 極慢推進（一個樂句 1.00 → 1.03） | 凝視、呼吸 | 靜段、片尾 |
| 長卷平移（橫向，由右往左） | 時間流動、旅程 | 主歌敘事、長卷 |
| 立軸下移（由上往下） | 由天到地 | 開場、瀑布、落下的東西 |
| 落印震動（3 px） | 句點、確定 | 段落結尾 |
| 推進到紙紋 | 細節、內省 | 間奏 |

- 允許的轉場：墨漫過整個畫面再淡回紙；整張畫淡回空白的紙，再畫下一張（留白溶接）；卷軸捲動；平移接平移。
- 禁止的轉場：兩張墨畫交叉溶解（墨會變成髒灰）、閃白、擦除特效、3D 翻頁。

## 7. 聲音調色盤 Sound

- **樂器：** 古琴（泛音、滑音）、簫、笛、琵琶輪指、木魚、梆子、磬、大堂鼓。用合成器時：泛音豐富的撥弦、緩慢的 pad、單一的鐘。
- **擬音：** 筆刷過紙的沙沙聲（寬頻雜訊，最響處對在行筆最快的地方）、點的短促乾聲、蓋印的悶木頭聲、紙張翻動、水滴。
- **環境：** 遠雨、風、溪水，都要很小聲。
- **靜默：** 留白就是靜默。印章前一拍可以讓整個樂團停下（stop），讓落印成為唯一的聲音。
- 用 `studio sfx` 的配方近似（建議值，示範本身沒有聲音）：

  | 畫面 | 配方 | cue 設定 |
  |---|---|---|
  | 主筆 | `whoosh` | `sync: "peak"`、`role: "transition"`、`gain: -12` |
  | 點苔 | `tick` 或 `pluck` | `pluck` 的 `params.note` 用歌曲調內的音，`gain: -14` |
  | 渲染滲開 | `pad` 或 `shimmer` | `gain: -20` |
  | 落印 | `impact` | `role: "brand"`、`gain: -8` |
  | 片尾 | `bell` | `params.note` 用主音 |

- 不要：一串 FM 合成器的「叮叮叮」琶音（Opus 的預設聲音；片尾一聲鐘可以）、EDM 上升音效、電影預告片的 braam。

## 8. 原生招式 Native moves

| 招式 | 做法 | 適合的內容 |
|---|---|---|
| **一筆畫成（勾）** | 一條線從頭畫到尾，長度是一個樂句 | 山脊、河流、人的輪廓、旋律線、情緒的起伏 |
| **墨暈（滲）** | 落筆之後慢慢暈開 | 回憶、眼淚、延長音、殘響、情歌的長音 |
| **點苔（點）** | 一串點落在拍上 | 八分音符的 hi-hat、雨滴、腳步、倒數、星星 |
| **落款蓋印** | 紅印落在小節第一拍 | 段落結尾、副歌最後一個字、片尾署名、做出決定的時刻 |
| **留白呼吸** | 畫面幾乎全是紙，只有一筆 | 前奏、break、歌詞的停頓、孤獨 |
| **長卷平移** | 橫向卷軸展開，敘事往前走 | 旅程、季節更替、一天的時間、主歌敘事 |
| **飛白收筆** | 筆乾掉，散成毛絲 | 句尾漸弱、淡出、速度感、離別 |
| **濃淡分層** | 近濃遠淡疊出空間 | 回憶的距離、群山、人群、時間的層次 |

## 9. 媒材的陷阱 Pitfalls

這些都是做示範時真的遇到的問題。

| 症狀 | 原因 | 對策 |
|---|---|---|
| 筆畫像電纜或管子 | 每根毛畫成平滑、等濃的平行線 | 先畫實心筆身，再刮出飛白；縫只在乾的段落打開 |
| 濕的筆身上出現白色虛線 | 門檻附近的高頻雜訊讓縫一開一關；小數次數的迴圈至少跑一次 | 雜訊只在開始乾時才作用；次數用隨機取整 |
| 筆尖像蟲頭 | 揭開遮罩的前端是半圓 | 遮罩在筆尖收窄，6 個取樣點內從 0.35 R 變成 R |
| 渲染像陰影或塑膠漸層 | 用一條條模糊線疊起來，斜坡處的線變密、變深 | 依「離山脊的距離」逐像素算濃淡，再加兩層 fbm |
| 山脊旁多一條白色光帶 | 遠山的霧剛好貼著近山脊、寬度固定 | 霧線離山脊要有起伏，並用 120 px 慢慢淡出 |
| 遠近山重疊處髒灰 | 兩層渲染疊在一起 | 遠山在近山上方化成霧（留白） |
| 畫面像向量插畫 | 線的寬度固定 | 壓力變化、粗糙邊、墨暈、飛白，至少要有三項 |
| 太滿 | 想讓每一拍都有新東西 | 一拍最多一個新筆畫，留白至少六成 |
| 渲染很慢 | 每幀重畫筆刷 | 筆畫離屏畫一次，每幀只揭開；滲開用半解析度遮罩 |
| 字變成方塊 | 字型子集沒有新字 | 改字後執行 `studio fonts` |

## 10. 引擎 Engine

[`demo/shots/ink.js`](demo/shots/ink.js) 匯出這些函式。複製到自己專案的 `shots/` 裡再 import：

| 函式 | 作用 |
|---|---|
| `paper(W, H)` | 宣紙底圖 |
| `sample(fn, x0, x1, step)` | 沿 `y = fn(x)` 取樣，每點附法線 |
| `brushStroke(pts, { width, pressure, dry, tone, hairs, seed })` | 離屏畫好一整筆；`pressure(s)`、`dry(s)` 是沿筆路 0–1 的函式 |
| `reveal(ctx, stroke, p)` | 揭開到進度 `p`（0–1） |
| `wash(W, H, ridge, { alpha, depth, x0, x1, seed, pool, soft, mist })` | 山脊下的渲染 |
| `soak(ctx, wash, u, scratch, W, H)` | 渲染滲開到 `u`（0–1）；`scratch` 是半解析度的 `[canvas, ctx]` |
| `seal(text, size)` | 白文印 |

- **速度：** 8 秒示範以 1080p 渲染約 24 fps（RTX 3090 Ti）。所有筆畫和渲染在載入時算好，每幀只畫紙、兩個滲開遮罩和揭開的裁切。
- **可重現：** 隨機都來自 `rng(seed)` 和 `noise1`。`studio verify` 通過，18 幀在全新的瀏覽器裡、任意順序下都一樣。
- **限制：** `sample()` 只處理由左往右的路徑（`y = f(x)`），`brushStroke` 沿筆路的濃淡漸層也依賴這一點。直的或繞圈的筆畫（竹子、瀑布、書法）需要改成依弧長取樣，並把漸層換成逐段的不透明度。

## 11. 變化空間 Variations

以下都和示範（四小節畫一幅山水）差很遠。

**結構**

1. **長卷：** 整首歌是一幅橫向長卷，鏡頭由右往左平移（手卷的方向）。每個段落是卷上的一景，副歌墨色最濃。
2. **一字一畫：** 每句歌詞寫一個大字，寫完後筆畫化成風景，例如「山」字的三筆變成三座山。
3. **四季冊頁：** 四個段落是四頁冊頁（春、夏、秋、冬），換頁用留白溶接，每頁只有一個主題物。

**開場**

1. 一滴墨落在紙中央，暈開的那一刻就是第一拍的大鼓。
2. 從全黑的墨開場，水把紙白洗出來，畫面慢慢浮現。白是洗出來的，不是畫上去的。
3. 一整個小節只有紙和聲音（風、筆刷），第一筆落在第二小節的第一拍。

**結尾**

1. 最後一個和弦延長時，整幅畫由上往下被水洗淡，回到空白的紙。
2. 卷軸收起，畫面捲成一條線後消失。
3. 墨漫過整個畫面變成黑底，最後一個字以留白的紙色出現。
