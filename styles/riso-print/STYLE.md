# Riso 印刷 · Riso Print

> **In short.** Three spot inks (fluorescent pink, blue and yellow), each printed as a layer of its own and multiplied onto warm paper, so that wherever two overlap they make a third colour. No ink lines up exactly with the others and none lies evenly. Both change twelve times a second, as if every frame had come off the machine on its own. The demo is 8 seconds on a 120 BPM grid. The three passes print on the first three beats and the registration kicks on the backbeats. In bar 3 a loupe snaps into the halftone, and in bar 4 the top sheet is pulled off the stack to show copy No. 02.

## 1. 本質 Essence

- **一色一版。** 每個顏色是一張獨立的版，各自過一次機。畫面上所有的顏色，都來自三種油墨和它們的重疊。
- **疊印出新色。** 油墨是半透明的，疊在一起是相乘（multiply）：粉紅＋藍＝深紫、粉紅＋黃＝橘紅、藍＋黃＝綠。三種油墨加上紙，一共七個顏色。
- **對不準是特色。** 每一版都偏幾個像素、歪零點幾度，而且每一張紙都不一樣。套準十字和色票條就是讓人看見這件事的地方。
- **墨不會均勻。** 大片的色塊有墨斑、針孔和顆粒，網點的邊緣是毛的。
- **每一格都是重新印的一張。** 墨斑和套準以每秒 12 次變化，像一疊印刷品快速翻過。
- **平面。** 沒有光影、沒有透視；要有立體感，只能靠網點的疏密。

它不是：

- 不是扁平插畫加雜訊濾鏡。顏色一定要分版，重疊一定要相乘，不能用第四個顏色去「畫」疊印區。
- 不是 CMYK 四色印刷。Riso 用的是特別色（spot color），螢光粉紅這種顏色 CMYK 印不出來。
- 不是故障藝術。錯位是幾個像素的機械誤差，不是 RGB 分離，也不是數位撕裂。
- 不是復古濾鏡：沒有暗角、漏光、刮痕、泛黃。
- 不是網版印刷的厚墨。Riso 的墨薄而透。

### 禁用清單 Ban list

- 第四種油墨，或直接拿疊印色（深紫、橘紅、綠）去畫東西。疊印色只能由兩版重疊產生。
- 漸層。深淺只能用網點做。
- 陰影、發光、模糊、半透明漸變。唯一的例外是換張時紙張本身的影子：那是紙，不是墨。
- 白色的油墨。最亮的顏色就是紙；要白就留白，或在版上挖空。
- 完美對齊。任何一版的偏移都不能是 0。
- 平滑的補間。所有變化都以每秒 12 格跳動（`stepTime`）。
- 3D、透視、旋轉的攝影機。
- 平滑的推拉鏡頭。要放大就在拍上跳一級。

## 2. 材料與渲染 Material

真實的媒材是理想科學的 RISO 孔版印刷機：熱感印頭在蠟紙母版上燒出細孔，母版包在油墨滾筒上，紙從滾筒下方通過，墨從細孔裡被壓到紙上。一個滾筒只有一種顏色，多色印刷就要讓紙過好幾次機，每次的位置都差一點。墨是半透明的大豆油墨；母版上的孔是一個一個的點，所以實地色塊會有顆粒。這個風格的長相，全部來自這幾件機械上的事實。程式的對應做法都在 [`demo/shots/riso.js`](demo/shots/riso.js)。

- **一次一版（`print`）。** 每一版先在一張離屏畫布上用油墨的顏色畫好，用 destination-out 打上墨斑和針孔，再用 `multiply` 疊到紙上。三版共用同一張畫布，畫完一版就清空。
- **套準（`registration`）。** 每一版在每一張紙上有固定的偏移（±3.5 px）和旋轉（±0.0015 弧度），每一格（1/12 秒）再抖 ±0.7 px。踢動時往隨機方向跳 7–13 px，以 0.07 秒的半衰期逐格回位。
- **過機（`fed`）。** 一版從紙的上緣往下，分三格印出。裁切範圍在紙的座標裡，在套準偏移之前。
- **墨（`inkTexture`）。** 兩張遮罩。墨斑是四分之一解析度的 fbm，最多吃掉 24% 的墨，每一格換一個取樣窗。針孔與顆粒是一張 256 px 的貼圖，同一張紙上固定不動（原因見第 9 節）。
- **網點（`halftoneBall`）。** 網線轉 15°，間距 16 px，每個點的面積等於它的色調。每個點的輪廓用 28 個頂點和四個諧波做成不規則的形狀，只有放大才看得出來。全部預先算成一個 `Path2D`。
- **紙。** `#F5F0E6`，加上紙屑和纖維，也畫成 `Path2D`，放大時仍然清楚。
- **大字（引擎的 `textSprite`）。** 210 px 的標題在放大鏡第一級會變成 336 px，所以在載入時先畫成圖。
- **攝影機（引擎的 `camera`）。** 版、紙、墨的紋理全部畫在世界座標裡。放大時網點、針孔、紙屑一起放大，像真的拿放大鏡看。

## 3. 色彩邏輯 Colour

| 角色 | 色值 | 規則 |
|---|---|---|
| 紙 | `#F5F0E6` | 背景，也是唯一的「白」 |
| 黃 Yellow | `#FFE800` | 最淺的一版：大面積的色帶、波形 |
| 螢光粉紅 Fluorescent Pink | `#FF48B0` | 主角：網點、細環 |
| 藍 Blue | `#0078BF` | 所有的字和線 |

油墨的螢幕色值取自 [riso-colors](https://github.com/mattdesl/riso-colors) 整理的 [stencil.wiki](https://stencil.wiki/colors) 色表（Pantone 近似：806 U、3005 U、Yellow U）。螢光粉紅在螢幕上無法真正重現，這只是近似值。

示範實測（No. 02 右下角的色票條）。理論值是紙色乘上油墨；實測比較淺，因為墨斑和針孔讓紙色透出來。三版全疊的理論值是 `#001D00`，幾乎是黑色，所以示範沒有三版全疊的大面積：

| 印出來的顏色 | 實測 | 100% 覆蓋的理論值 |
|---|---|---|
| 黃 | `#F5DE25` | `#F5DA00` |
| 粉紅 | `#F563AB` | `#F5449F` |
| 藍 | `#1D80B3` | `#0071AC` |
| 黃＋粉紅 | `#F55615` 橘紅 | `#F53E00` |
| 粉紅＋藍 | `#2D3185` 深紫 | `#002077` |
| 藍＋黃 | `#2D7E1C` 綠 | `#006700` |

- 最淺的墨先印（黃 → 粉紅 → 藍）。相乘的結果和順序無關，但過機的動畫會讓人看見順序。
- 設計時就決定哪裡要出現哪個疊印色，讓三種疊印都出現在主畫面上。示範的安排：「的」壓在網點球上（深紫）、「聲音」壓在黃色色帶上（綠）、波形穿過網點球的下緣（橘紅）。
- 字用最深的那一版（藍）。小字不要用黃色，在紙上幾乎看不見。
- 網點色調最高 0.8（相鄰的點剛好相接是 0.785），最低 0.09。全實地交給色塊，不交給網點。

## 4. 字型與字幕 Type

- **Noto Sans TC**（SIL OFL 1.1）可變字重：標題 900（210 px）、環形字和頁首 700（26 px）、小字 500（20–26 px）。
- 字只印在一版上。字壓到另一版時，疊印色會自己出現，不要另外畫。
- **同一版要挖空。** 同一種墨的東西交錯，交錯處只會是一團藍。示範的環形字經過標題時被裁掉（`knockout`），只讓粉紅細環穿過標題。
- **環形字。** 一句話重複排滿一圈，重複次數和字距自動計算；字頭朝外，順時針讀。
- **歌詞。** 一句一行，印在藍版上，在拍上用「過機」由上往下出現，或整句一次蓋印。一行 10 個字以內，字重 700 以上：細筆畫會被墨斑和針孔吃掉。
- 小字至少 20 px。
- 改了文字之後，執行 `node tools/studio.mjs fonts styles/riso-print/demo` 重新子集化字型。

## 5. 動態質感 Motion

- 輸出 30 fps，畫面內容以每秒 12 格跳動（`stepTime(t, 12)`）：墨斑、套準的微抖、環形字的轉動、踢動的回位、換張。
- 沒有補間。每一次變化都是「下一張印好的紙」。
- 重音用**套色踢動**：三版往不同方向跳開，三、四格內回到原位。
- 進場用**過機**（由上往下分三格印出），或整版一次蓋印。
- 退場用**換張**（紙被抽走）。
- 版上的內容相對於自己的版永遠不動。會動的是版的位置、墨，以及整張紙。

## 6. 鏡頭語法 Camera

| 動作 | 表達 | 用在 |
|---|---|---|
| 鎖定 | 一張印刷品 | 大部分的時間 |
| 放大鏡跳級（在拍上跳到 1.6×、2.6×、4.2×） | 細看、揭露材質、聚焦 | build、副歌前、間奏 |
| 跳回全景 | 解決、回到整體 | build 的最後一拍 |
| 換張（紙被抽走） | 下一頁、換段、時間過去 | 段落轉換、副歌第一拍 |
| 疊張（新的一張從上面落下） | 累積、新的版本 | 重複的段落 |

- 放大以一個固定點為中心：那一點在畫面上的位置不變，其他東西以它為中心放大（示範的 `P` 選在網點球的邊緣，那裡同時有三種墨和三種疊印色）。
- 放大一定是跳級，不做平滑推鏡。
- 禁止：晃動、旋轉、透視、模糊轉場、交叉溶解。

## 7. 聲音調色盤 Sound

- **音色：** 機器和紙。乾淨的鼓組、一點磁帶飽和、lo-fi 的質感。印刷機運轉本身就是節奏：滾筒每轉一圈一聲。
- **音樂：** bedroom pop、city pop、lo-fi hip hop、indie。85–120 BPM。
- **靜默：** 換張前半拍可以讓樂器全停，只留紙被抽走的聲音。
- 用 `studio sfx` 的配方近似（建議值，示範本身沒有聲音）：

  | 畫面 | 配方 | cue 設定 |
  |---|---|---|
  | 過機 | `typing`，每格一下，一版三下 | `gain: -14` |
  | 套色踢動 | `click` | `gain: -10` |
  | 放大鏡跳級 | `pop` | `gain: -10` |
  | 跳回全景 | `impact` | `role: "transition"`、`gain: -8` |
  | 換張 | `whoosh`（`params.dur: 0.3`） | `sync: "peak"`、`gain: -12` |
  | 細環彈開 | `tick` | `gain: -20` |

## 8. 原生招式 Native moves

| 招式 | 做法 | 適合的內容 |
|---|---|---|
| **過機** | 一版由上往下分三格印出 | 開場、新的段落、新的一句歌詞、一個角色登場 |
| **套色踢動** | 三版往不同方向跳開，再逐格歸位 | 小鼓、重音、副歌第一拍、情緒爆發 |
| **疊印揭露** | 兩版在拍上相遇，交集處出現第三個顏色 | 兩個人相遇、合唱、和聲進來、兩個想法結合 |
| **放大鏡** | 在拍上跳級放大到網點 | 細節、仔細看、build、真相 |
| **換張** | 最上面一張被抽走，下面是另一張 | 換段、時間過去、翻頁、下一個版本 |
| **逐格翻頁** | 每一格是不同的一張印刷品（套準與墨斑都不同），內容逐格改變 | 走路循環、波形、手繪動畫、心跳 |
| **網點呼吸** | 網點的色調跟著音量變化（預先算 4–6 張不同色調的 `Path2D` 輪流用） | 低音、呼吸、光線變化、副歌的能量 |

## 9. 媒材的陷阱 Pitfalls

| 症狀 | 原因 | 對策 |
|---|---|---|
| 放大後網點像電腦畫的圓 | 每個點都是正圓，邊緣太乾淨 | 輪廓加幾個諧波做成不規則形；1× 時看不出差別，放大才有墨的感覺 |
| 檔案很大：8 秒 18.1 MB（瑞士動態排版 0.5 MB、水墨 1.6 MB） | 1 px 的顆粒每格都換，x264 每一格都要重新編碼雜訊 | 針孔與顆粒在同一張紙上固定，只讓墨斑每格換：14.6 MB。再拿掉套準微抖是 11.0 MB。上傳前在手機上看一次平台二次壓縮後的樣子 |
| 環形字穿過標題，糊成一團 | 同一種墨沒有疊印色，交錯處只是一團藍 | 同一版的元素交錯時挖空：環形字在標題的範圍裡被裁掉 |
| 換張的第一格幾乎沒動 | 用了 `ease.in`，前 25% 的時間只走了 0.2% | 換張改用逐格的位置表（`PULL`），第一格就看得到 |
| 第一格是一張白紙 | 第一版由上往下印，上面三分之一沒有黃色的東西 | 接受它（紙剛進機器），或把第一版的元素放在畫面上方 |
| 字變成方塊 | 字型子集沒有新字 | 改字後執行 `studio fonts` |

## 10. 引擎 Engine

[`demo/shots/riso.js`](demo/shots/riso.js) 匯出這些函式和常數：

| 名稱 | 作用 |
|---|---|
| `PAPER`、`INK` | 紙色，以及三種油墨 `{ yellow, pink, blue }` |
| `inkTexture(W, H, { seed, blotch, holes, grain })` | 墨斑與針孔兩張遮罩：`{ blotch, q, holes }` |
| `halftoneBall(center, R, { pitch, angle, light, lo, hi, seed })` | 受光球體的網點，一個 `Path2D`（畫的時候裁切到球內） |
| `riso` | 示範的鏡頭 |

- **速度：** 每格繪製約 33 ms（換張時有兩張紙，約 50 ms）。8 秒示範以 1080p 算圖 13.5 fps（RTX 3090 Ti），大部分時間花在 x264 編碼滿版的顆粒。
- **可重現：** 所有隨機都來自 `rng(種子)`，種子由版、紙張編號和第幾格組成。`studio verify` 的 18 幀全部相同。
- **限制：** 網點路徑在載入時算一次（約 1,800 個點，每點 28 個頂點），不要在 `draw()` 裡重算；要讓網點隨音樂變化，就預先算好幾張輪流用。

## 11. 變化空間 Variations

以下都和示範（一張海報在四小節裡印好、踢動、放大、換張）差很遠。

**結構**

1. **一張海報的一生：** 整首歌是同一張海報從白紙開始被印出來。每一段加一版或一個元素，副歌時三版到齊，最後一段一張一張被翻過。
2. **翻頁動畫：** 一個角色的走路循環，每一格是不同的一張印刷品，以 12 fps 翻動；歌詞印在每一頁的角落。
3. **小誌（zine）：** 一首歌是一本小誌，每小節翻一頁。每頁一句歌詞，配一張用網點重印的照片（照片的亮度換成網點大小）。

**開場**

1. 白紙上先出現四角的套準十字，一版一版到齊，第一句歌詞時才開始過機。
2. 從 4.2× 的網點特寫開始，每一拍退一級，最後才看見整張。
3. 一疊紙從畫面上方掉下來，最上面那張就是第一個畫面。

**結尾**

1. 最後一拍三版同時往不同方向飛出畫面，只剩白紙。
2. 把整首歌印過的畫面一張一張快速翻過，停在 No. 50 / 50。
3. 印刷機缺墨：最後一版越印越淡，墨斑越來越多，最後只剩套準十字。
