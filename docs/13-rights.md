# 13 版權與發布安全

> 這一章是整理社群做法與常見風險，**不是法律意見**。商業用途或有疑慮時，請諮詢專業人士並以權利人的公告為準。

這一章只在片子要公開時用得到。私下練習的片可以用任何歌，歌和歌詞留在 `projects/` 裡、不進版控。

程式路線的好處之一是**畫面幾乎都是你自己的**：每一幀都是程式畫的。風險集中在你放進去的東西：歌、歌詞、角色、字型、素材、真人、品牌。

## 歌曲

| 情況 | 做法 |
|---|---|
| 自己的歌、委託的歌 | 最安全；保留授權證明 |
| 原作者有公開二創規範 | **先讀規範**。例如 Mili 的官方版權指引：個人、非商業，並標示 AI 生成內容（穆阿蒂布、Nyankomintsu 都依此發布） |
| VOCALOID 角色 | 角色有自己的授權，例如初音未來的 Piapro Character License（PCL）；《千本櫻》MV 在說明欄附上 PCL 連結 |
| 一般商業歌曲 | 沒有授權就不要做成公開影片。X 上有人為一首商業樂團的歌做了 13 分鐘 MV，這是明確的版權問題 |
| AI 生成的歌 | 看服務條款；沒有任何 AI 音樂平台保證不被內容比對系統認領（plotome 的風險表） |
| 公眾領域的曲子 | 錄音不一定是公眾領域；找錄音本身是公眾領域或 CC0 的版本（例如 Kimiko Ishizaka 錄製的巴哈） |
| 授權音樂庫 | 看清楚能不能用在影片同步（sync）、能不能商用、是否只限平台內 |

plotome 整理的音樂庫比較：

| 音樂庫 | 說明 |
|---|---|
| 剪映／必剪內建 | 只能在該平台使用 |
| Free Music Archive | 每首授權不同；NC＝不可商用，ND＝不可同步到影片 |
| Pixabay Music | 免費、可商用、不需署名，但部分曲目註冊了內容比對，可能被認領 |
| Epidemic Sound | 訂閱制，可依情緒與 BPM 搜尋 |
| 曲多多、光厂、VFine | 按月或按首；個人授權不等於企業授權 |

他自己的做法：只用允許同步的曲目，每一首都寫進片尾與說明欄（Lee Rosevere、Chris Zabriskie 的 CC BY 4.0 曲目、HoliznaCC0 的 CC0 曲目、公眾領域的巴哈錄音），再加上自己的主題動機。

**不要用**：官方 PV 或 MV 的畫面素材、藝人的影片片段、來源不明的迷因 BGM（觀眾也聽膩了）、任何你說不出授權的音樂。悬剑听泉 的實驗裡，Opus 被要求做動畫 MAD 時自己下載了 18 支官方 PV 來剪，這在公開發布時是版權問題。

## 歌詞

- 在影片畫面上顯示歌詞，是同人 MV 的常態，但仍以權利人的規範為準。
- **公開的程式庫不要放歌詞全文與音檔**，做法見 [05](05-lyrics.md#歌詞的版權)。

## 角色、真人與品牌

- **同人角色**：遵守原作的二創規範。角色素材若是 CC BY-NC-SA 4.0（例如 world.execute(me) 系列常用的剪影素材），**用到它的部分也要用同樣的授權**，而且不能商用。
- **真人**：plotome 的風險表提醒，**辨識得出來的人，畫成線稿也還是肖像**。在世的真人用文字頭像代替，只寫名字。netsu-ijou 的作者在一張臉上加了遮蔽條。
- **聲音複製**需要本人同意。
- **品牌與商標**：不要用真實品牌，除非你擁有權利。路北路陈的設計科普裡，海報與 Logo 都是虛構的重新詮釋，並註明「品牌僅作說明」。Apple 50 年的作者加了「非官方同人作品」與商標聲明。
- **遊戲 IP**：複製知名遊戲的地圖或角色，風險很高。

## 字型、程式與素材

| 類別 | 規則 |
|---|---|
| 字型 | 只用開源授權（SIL OFL 等）；字型檔放專案裡；列入 CREDITS |
| 程式框架 | **開源不等於可以免費商用**：Remotion、GSAP、react-bits 等都有自己的授權條款（plotome 的風險表），使用前確認 |
| 3D 模型 | Poly Haven 是 CC0；Sketchfab 每個模型授權不同（Apple 50 年使用的 iPhone 模型是 CC BY 4.0，作者署名在片尾） |
| 圖片 | 素材圖避開可辨識的臉與商標 |
| 地圖 | 自製的地圖在部分地區發布需要審查；用示意圖，或官方核准的地圖 |
| 地理與科學資料 | Natural Earth、SRTM 地形資料可自由使用；寫明資料來源與年份 |
| 筆順資料 | KanjiVG 是 CC BY-SA，衍生資料要同授權 |
| 別人的程式碼 | 看授權：MIT／Apache／ISC 可以改用並保留聲明；AGPL、非商業授權、沒有授權的，只能參考想法 |

**AI 生成素材**：保留生成器的浮水印與 AI 標示，不要去除。有些開源工具附帶去浮水印的腳本，不要用。

## AI 標示

- **一開始就標示**。比特新语兩週漲到約 50 萬粉絲，被發現是 AI 製作、而且跨平台轉發時沒有勾選「AI 生成」後，有留言稱掉了約 10 萬粉。
- 中國大陸的 AI 生成內容標示規定自 2025 年 9 月起施行（plotome 的風險表）；平台通常有「AI 生成」的勾選欄位，YouTube 也有合成內容的揭露設定。
- 標示可以很簡單：「本片畫面由 Claude Opus 5.5 撰寫程式逐幀繪製」（算法之外每支片都這樣寫）。
- 有 AI 角色的情感敘事時，可以加一句提醒。开车必备导航的說明欄寫：片中 AI 的情感是虛構的，請謹慎看待 AI 陪伴。

## 光敏警告

有快速閃爍或高對比閃動時，在標題、說明欄頂端、影片開頭都寫上警告與**時間範圍**。範本：

```
⚠ 光敏警告：本片 2:33–3:17 有快速閃爍與高對比畫面，對光敏感的觀眾請斟酌觀看。
```

規則與檢查方法見 [11](11-review.md#光敏安全)。

## 知識類影片的事實

- 每個事實都要有來源：`FACTS.md` 每一行寫主張、來源網址、原文摘錄（lemo-opuscar）。
- 畫面上的數字來自真實的計算或模擬，並說明範圍與假設（見 [06](06-storyboard.md#模擬那個主張)）。
- 加上適當的聲明：「僅作示意，不構成投資建議」（plotome）、「動畫為模擬演示，非真實影像；數據截至 2026-09-26」（风之谷AI）。

## 轉載

- 轉載別人的作品前先取得同意，並清楚標示原作者與連結。白雪仅当雪白 轉載 mexicat 的 P(doom) MV、pixel像素直播间 轉載 PDoomVideo，都註明了來源。
- 你的作品也可以寫清楚轉載規則。竹纸 的說明欄寫「未經授權轉載者，自行承擔所有 token 費用」。

## 說明欄範本

### 原曲資訊（同人 MV）

```
原曲：〔曲名〕
作詞／作曲：〔…〕　編曲：〔…〕　演唱：〔…〕
原版 MV：〔繪師〕／〔影像〕　連結：〔…〕
角色：〔角色名〕© 〔權利人〕，依〔授權名稱與連結〕使用
本片使用原曲音訊；畫面為重新製作的非商業同人作品，相關權利歸原權利人所有。
本片依〔原作者〕的官方二創規範發布：〔連結〕
```

（結構參考《千本櫻》MV 與《人是貓》的說明欄。）

### 製作資訊

```
畫面：每一幀由 Claude Opus 5.5 撰寫程式繪製（Canvas 2D／WebGL），無影片生成模型
導演、審查：〔你的名字〕
歌詞對齊：〔工具〕＋人工校對
音效：〔程式合成／音效庫名稱與授權〕
字型：〔字型名稱〕（SIL OFL 1.1）
工具：claude-studio（MIT）
本片含 AI 生成內容。與 Anthropic 及原作者無關，亦未獲其背書。
```

角色分工寫清楚也很好。路北路陈的說明欄寫：我負責方向、決策與聽覺品管；Opus 5.5 是設計主管（選題、腳本、事實查核、分鏡、視覺、所有鏡頭程式、音效設計、封面）；Codex 是工程主管（渲染管線、配音對齊、混音、字幕）。

- [ ] 真人、品牌、遊戲 IP 都處理過

- [ ] 知識類影片的事實都有來源
