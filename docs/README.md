# Claude Studio 知識庫

用 Claude Opus 5.5 製作動畫與 MV 的完整方法：從一首歌或一個點子，到一支可以發布的影片。

這份知識庫整理自 2026 年 9 月 22 日 Opus 5.5 發布後一個月內的公開資料，篩選標準是**實際成效**：

- Bilibili 上依播放數與收藏數排序的案例（優先看高收藏率作品；收藏率是內容品質最可靠的訊號）
- 案例作者本人在 X、Bilibili 的說明與留言回覆
- 48 個開源專案的原始碼與文件（逐一確認授權）
- Anthropic 官方文件

內容農場、只收集提示詞的帳號、「留言拿工作流」這類誘餌內容都不採用。每一條建議盡量附上出處與數字，方便你自己判斷。

## 慣例

- 數字都標註來源與時間；播放數是 2026 年 10 月中下旬的快照。
- 「官方」只指 Anthropic 文件；社群說法會標明「社群經驗」。
- 引用他人做法時一律改寫成自己的話並附連結，不轉貼別人的完整提示詞。
- 本知識庫與 Anthropic 無關，也不代表 Anthropic 立場。
