# 07 風格與美術

## 先認出「預設 Opus 風」

不指定風格時，Opus 會收斂到一種觀眾已經認得的樣子。留言裡反覆出現的特徵：

- 深色背景、置中大字、漸層，所有東西同時淡入（xilo 與卡尔的AI沃茨都點名這個「預設樣子」）
- 滿屏光效（在公司楼下捡钱：「它所謂的炫技就是炫光」）
- FM 合成器的「叮叮叮」開場、空靈合成器（《熵》留言：「Opus 很喜歡用 FM 合成設計聲音」）
- 紀念碑谷式的幾何感、所有數學片都同一種風格（电子智人、地球创造会的留言）
- 霓虹賽博龐克、發光大腦、駭客任務數字雨、鏡頭光暈湯、粒子星雲、「AI 感」素材圖（mexicat 的禁用清單）

留言的總結很直接：「簡單提示詞出來的就是預設的 Claude 風格」。避開它的方法只有一個：**給具體的風格**。

## 參考比形容詞有用

- **給參考圖，不要只寫形容詞**。汤姆CC：給幾張參考圖比文字精準得多。
- **說出風格的名字，勝過描述它**（rexan_wong）。沒有參考時，它會退回置中文字加漸層與淡入。
- 同一份長簡報，anabology 只多給了 Midjourney 和一張情緒板，就做出一支完全不同、約 2,000 萬觀看的片。
- 素材和參考**自己找、自己放進資料夾**。可爱归归的經驗：讓 AI 自己上網搜很容易觸發安全檢查。

參考也會把片拉向它自己：代理看過什麼就會用什麼，所以先想、再參考（[03 G2](03-workflow.md#先自己想再看參考)）。

把品味詞翻譯成規格（阿珍的第二條技巧）：

| 你說的 | 要寫成 |
|---|---|
| 科技感 | 深色背景、白字、科技藍或青色強調、具體的 hex |
| 電影感 | 景別（遠景／中景／特寫）、鏡頭焦段、光線方向 |
| 衝擊力 | 「第一幀就呈現結果，主體快速放大後停住，音效落在停住那一刻」 |
| 高級 | 留白、一種強調色、一種字型、精確的字距 |

## 風格卡

路北路陈每一集設計科普都附一張風格卡，並寫上「把這段描述複製給 AI」。格式：

| 欄位 | 內容 |
|---|---|
| 名稱 | 例：瑞士國際主義風格 |
| 一句話 | 這個風格的本質 |
| 字型 | 字型家族、字重、角色 |
| 色票 | hex，標明用途與面積比例 |
| 版面 | 網格、對齊、留白 |
| 圖形與物件 | 允許出現什麼 |
| 質感 | 平面、紙、顆粒、磨損 |
| **動態規則** | 什麼會動、怎麼動、節奏 |
| 容易混淆的風格 | 它不是什麼 |
| 禁用清單 | 明確不要的東西 |

他公開的幾張卡的關鍵數字（選定這種風格之後，可以直接當規格的起點）：

| 風格 | 色票與規則 |
|---|---|
| 瑞士風格 | 12 欄網格；新怪誕無襯線體兩種字重；巨大標題對比極小內文；靠左不齊右；不對稱；黑、米白加一個紅 `#DA291C`；平面，不要陰影、漸層、質感、插畫 |
| 卡帶未來主義 | 綠 `#74FF9A`、琥珀 `#FFB23E`；等寬像素字型；掃描線、光暈、打字機；**每 12 幀一跳，不用平滑緩動**；不要霓虹、不要毛玻璃 |
| 風格派 | 黑線約畫面寬度 1.5%，只有水平與垂直；紅 `#D0302A`、黃 `#EBC226`、藍 `#1D3F8C`、米白 `#F4F1EA`；**只沿水平垂直運動，線條切入、色塊刷上，不彈跳、不旋轉** |
| NASA 龐克 | 白與淺灰硬體 `#ECE5D6`；面板、接縫、鉚釘、警示條紋、極小的全大寫標籤；復古四色條 `#4C5A68` `#7A7F4E` `#D2A85E` `#A8432F`；單一強調紅 `#D63A2C`；輕微磨損；不要霓虹、全息、漸層 |
| 包浩斯 | 紅 `#E2412C`、黃 `#F2C230`、藍 `#2F57B0`、底 `#F1ECE1` |

| 風格卡 | 一句話 | 媒材的格率 |
|---|---|---|
| [瑞士動態排版](../styles/swiss-kinetic/STYLE.md) | 12 欄網格、兩種字重、一個紅；每個動作落在拍點上，四分之一秒內結束 | 30 fps |
| [水墨紙本](../styles/ink-and-paper/STYLE.md) | 一筆落在拍點，墨暈之後才滲開，一方紅印收尾 | 30 fps |
| [Riso 印刷](../styles/riso-print/STYLE.md) | 三種特色墨各印一層、疊出第三色，每一張的對位都不一樣 | 12 fps |

| [藍圖](../styles/blueprint/STYLE.md) | 兩種線寬、淡的構造線、只給量測值的橘色，照製圖順序一筆一筆畫 | 30 fps |

卡片是選項，不是菜單：原樣套用只會做出那個傳統的示範（[03 G2](03-workflow.md#先自己想再看參考)）。

做這六張卡時量到、可以帶到任何風格的幾件事（細節在各卡的第 9、10 節）：

- **檔案大小幾乎都來自「每一格都換的紋理」。** 同樣 8 秒 1080p：Riso 的油墨顆粒每秒換 12 次，14.6 MB；瑞士排版畫好就不動，0.53 MB。平移本身不貴（藍圖 §6）。紋理跟著媒材的格率換，不要每一格都換。
- **大字用 `textSprite`。** 超過約 250 px 的字在 GPU 上，前後畫過什麼會讓字形差一兩個色階，`studio verify` 就不一致；先畫進自己的畫布再貼上（[engine/README](../engine/README.md)）。
- **置中的字一個一個出現時，先量整行。** 每多一個字就重新置中，字會邊寫邊往左滑（藍圖 §9）。
- **紙的雲斑和摺痕要在縮小播放時還看得見、又不能變成圖案**：藍圖紙的雲斑從亮 70／暗 110 降到 45／75；摺痕從 8% 提高到 16%。
- **一支片可以同時放幾張卡**：[examples/song-to-mv](../examples/song-to-mv/) 的副歌一小節一張，示範的時間由那首歌的拍子換算；每個示範要畫在自己的畫布上，示範用到的字型（水墨卡的 Noto Serif TC）要加進那支片的 `studio.json`。

## STYLE.md：風格只寫不變的東西

lemo-opuscar（59 種風格、MIT 授權）的風格檔有一條很重要的原則：**風格檔只寫不變的東西**，不寫故事、BPM、範例的時間點。故事每次從你的題目重新導演。本專案的 `styles/<id>/STYLE.md` 採用類似的結構：

1. **本質**：3–5 個特徵，以及它不是什麼（容易混淆的風格）。
2. **材料與渲染**：真實世界的媒材是什麼，程式怎麼模仿它。
3. **色彩邏輯**：規則，不是色盤（最多附一組範例色盤）。
4. **字型與字幕**：免授權字型、角色、字級；字幕要屬於這個世界。
5. **動態質感**：幀率與一拍幾、什麼會抖動、緩動、重量、出現與消失、什麼永遠不動。
6. **鏡頭語法**：運鏡 → 表達什麼 → 可以用在哪；允許與禁止的轉場。
7. **聲音調色盤**：樂器、音色、擬音材質、環境音、靜默；不寫配樂結構。
8. **原生招式**：這個媒材獨有的動作，每個附三個以上「適合的內容」。
9. **媒材的陷阱**與對策。
10. **引擎**：哪些程式可以重用。
11. **變化空間**：三種結構、三種開場、三種結尾，都要和範例差很遠。

例如水彩風格的幾條規則（lemo-opuscar）：紙就是白色；筆觸是半透明的變寬緞帶加 3–9 條飛白刷痕；渲染是同一個多邊形抖動三次、每次三分之一透明度（邊緣會積色）；顏色靠透明疊加（越深＝疊越多次），3–5 個色相加墨色，保留一個強調色；色階量化成 4–6 階讀起來像顏料，連續漸層讀起來像軟體。

## 色彩

### 一個強調色

- plotome 的元素表規定：**任何一幀只有一個橘色強調色**。
- 卡尔的AI沃茨：只用三種顏色，每格只講一個賣點。
- xilo：一個方案 2–4 個 hex。

### 色彩角色（EGSECDA）

從暗到亮排：墨色（取代純黑畫線）→ 陰影 → 中間調 → 強調（面積 ≤8%，定格時除外）→ 熱色 → 光暈 → 高光；外加一個殘影色（光暈的補色）和一組雙色調（文字對比 ≥7:1）。

- 每鏡一組色盤；色盤只在剪接或有動機的掃過時改變。
- 漸層映射的色階亮度要單調上升。
- 暖色場景不要用純黑線。

### 顏色是狀態，不是風格（Nyankomintsu）

顏色只在「發生了什麼事」的時候改變：關 → 開（第一個顏色是火花圖示在 15.11 秒亮起）→ 溫暖 → 錯誤（第一個紅色在 129.34 秒）→ 灰燼 → 熄滅。每個顏色有固定意義：橘＝我、米白＝你、紅＝錯誤、灰＝不在。

netsu-ijou 用**單一參數控制整體調色**：`heat` 從 0 到 1，驅動世界層的漸層映射、角色層的分開調色、光源亮度上限、介面顏色。整首歌的情緒就是 `heat` 的曲線。

| 逐像素質感：CRT、顆粒、網點、水、光暈 | WebGL 著色器（內容先畫在 Canvas，再上著色器） |
| 3D 產品、3D 文字、點雲、低多邊形、體素 | three.js |
| 黏土、寫實 3D、流體 | Blender |
| 數學推導 | Manim |
| 像素藝術 | 小畫布（如 128×96）整數倍放大 |

（綜合卡尔的AI沃茨的工具選擇與 xilo 的技術表。）

Blender 或生成工具做出來的畫面，變成逐格圖層接回片子，文字和世界仍然由程式畫（[10](10-render.md#其他工具做的畫面)）。

分層做：**內容 → 質感 → 聲音**，每一層都能單獨跑、單獨檢查（xilo）。

### 像素藝術的規格

majidmanzarpour 的像素巫師（43.9 萬觀看）等作品的規格格式：

- 邏輯解析度 128×96／160×90，放大到最大整數倍；關閉平滑（`imageSmoothingEnabled = false`）；座標取整數。
- 不要漸層、反鋸齒、陰影模糊、旋轉；固定 24–32 色色盤，「每個像素都來自這個色盤」。
- **姿勢參數平滑變化，但每幀量化到像素網格**，在 60 fps 裡讀起來像 8–12 fps 的精靈動畫；擠壓伸展只能以整像素為單位。
- 中文像素字：先畫在小畫布上，再以 0.5 透明度門檻二值化；邏輯尺寸至少 18 px（xilo）。
- **字越小，字重越輕**（本專案像素卡實測，Noto Sans TC）：18 px 用 400，700 以上「載」「歌」的筆畫就黏在一起；34 px 的標題用 500–700，900 時「像」的內部糊掉。
- **掃描線每條至少 3 列像素。** 180 條掃描線縮到 480p 只剩每條 2.67 列，會和像素格干涉出摩爾紋；720p 每條 4 列就乾淨。會被縮小播放的版本（手機預覽、GIF）把掃描線調淡。
- **檢查像素是不是真的像素**：關掉 CRT 效果算一張（像素卡用 `?crt=0`），確認每個放大後的格子都是單一顏色、而且在色盤裡。
- 雪花、撕裂這種每格都變的畫面最花位元：跟著畫面每秒換 12 次，不要每格換（像素卡從 4.4 MB 降到 3.8 MB）。

### 繪畫質感的做法

- **筆觸渲染器**（painted-rickroll）：每一筆帶有顏料高度，用來算厚塗的光影；畫布紋理；調色原則「暗部冷、亮部暖」；每一筆有塗上與刮除的時間，所以每個世界能被畫出來、也能被刮掉。
- **riso 賽璐珞轉描**（Pdoom 動畫版）：Kuwahara 平塗 → XDoG 墨線（帶抖動）→ 對到最近的 7 種油墨 → 陰影加 45° 網點 → 一拍二的抖動與版錯位 → 紙纖維、顆粒、暗角。
- **油畫化**（Austerlitz）：Kuwahara 濾鏡＋畫布織紋＋顆粒＋2.35:1 遮幅。
- **80 年代賽璐珞動畫**（lemo-opuscar）：噴槍背景＋硬邊陰影與高光的賽璐珞＋透過光與光暈＋VHS／CRT。角色一拍二、表演一拍三、鏡頭與光每幀都動。

## 角色

### 角色設定表

- 正面、側面、背面；3–4 種表情；2–3 個關鍵姿勢；色票。
- Pip 短片提示的做法：讓代理把參考圖**詳細描述回文件**（`docs/character_bible.md`）、用程式**從參考圖取樣色票**、定一條「換風格也不能變」的身分規則；然後把程式畫的角色並排放在參考圖旁，直到你說「對，就是他」。
- 废才俱乐部：三視圖（胸像、正面全身、側面全身）**在同一張圖裡生成再裁切**，比生成三次一致；每個角色有一個辨識記號（例如右眼下的痣），用來比對臉。
- netsu-ijou 的角色鎖定文件：官方設計元素表（髮型、頭飾、眼睛、外套、腰帶、鞋、機械特徵、身體比例、代表色 hex）＋核准的正背面參考。

### 會動的角色

- **2D 剪紙骨架**（Pip）：根 → 底盤 → 軀幹 → 脖子 → 頭；可替換的手勢；輪子依移動距離轉動；**程序化臉部系統**（大小、眼瞼、瞳孔、高光、眨眼 3–4 幀）；次要動作用阻尼彈簧；一個「風格皮膚」介面，換線條與材質但不改幾何。
- **表演要一拍一拍規劃**（Tao 的教訓）：「看檔案 → 伸手 → 抓住 → 拿起 → 遞出 → 放開」，不然角色會像貼紙一樣僵住。
- **預備、動作、跟隨**；用關鍵幀＋緩動混合姿勢，不要在 `if` 裡直接切換姿勢（除非是刻意的一幀喜劇效果）；手持物要在兩掌之間；滾動物體依距離 ÷ 半徑轉動（lemo-opuscar）。
- 肩膀的旋轉順序：先外展再屈曲（反過來舉起的手會交叉成 X）；手臂與軀幹重疊處不要描邊，會露出紙偶接縫（lemo-opuscar）。
- 角色動畫是程式路線公認的弱點（bradmillscan），要在骨架上多迭代。大肥鱼 MV 的 token 大多花在建 Spine 骨架上。

## 生成素材（混合路線 R5）

影片模型與圖像模型擅長有機的東西（人、手、布料、花開）。高收藏的混合作品有一套共同的控制方法。

### 程式負責世界，模型只負責一個角色

makevoid 的核心教訓：**去背的角色精靈疊在程式畫面上，效果遠好於整個場景由影片模型生成**。影片模型每一幀都重畫背景：道具會變形、顏色會漂、鏡頭會亂飄、會自己生出文字。所以：

- 影片模型每段只動**一個角色**，背景是純色綠幕（`#00B140`），鏡頭鎖定，不要地板、陰影、道具，全身在畫面內並留邊。
- 世界由程式＋靜態背景圖組成；角色在程式裡相遇。
- 全畫面生成最多一兩次，而且要有理由。
- 綠幕素材的去背見 [10](10-render.md#去背交給-ffmpeg我們量結果)。

plotome 的分工更簡潔：**程式管位置、結構、動作；生成模型管人和質感**。

### 讓生成素材聽話

- **風格聖經**：一段文字，原封不動貼進每一個圖像提示；hex 色和程式裡的常數共用（makevoid）。
- **不要讓模型畫字**：所有文字由程式畫。
- **提示裡的每個字都可能出現在畫面上**：废才俱乐部加了一句「臉、頭髮、眼鏡要和參考一致」，結果模型給沒戴眼鏡的角色加上眼鏡。每個字都要審。
- **生圖只拿中性素材，光和氣氛在合成時做**（netsu-ijou）：提示裡不寫光、時間、天氣和氣氛（月光、夜、雨、發光、柔焦、暗、陰鬱、高對比），讓模型畫中性的固有色、平均的光；人物畫在綠底上，場景畫成沒有人的空景。夜色、光源、倒影、雨和調色都在合成時做，煙霧、光暈這類半透明效果也是。畫法照這支片的風格：「中性」只是說圖裡沒有畫進光和氣氛，不是指定平塗。
- **不拿看起來像 AI 的圖當參考圖**：模型會連 AI 感一起學過去；拿生成圖當下一張的參考，一張接一張會越來越重。參考圖用人畫的作品，或使用者看過、認可不像 AI 的圖。
- **去掉 AI 塑膠感**：每個文生圖提示前加一段「霧面皮膚、看得見毛孔、不要磨皮、不要油光」（废才俱乐部）。
- **畫面上的文字用首尾幀**：先生成沒有字的首幀和字正確的尾幀，影片模型只動中間，6 次全對（废才俱乐部）。
- **AI 去背**：請圖像模型把同一張圖重畫成純綠背景，只取它的遮罩套回原圖像素，臉保持原樣（netsu-ijou）。
- **不要直接用生成的畫面**：Pdoom 動畫版的影片模型素材從不直接出現，全部經過轉描風格化；donaldjewkes 的《Claude Pop》把生成影片當參考底片，在上面用 JavaScript 重畫每一鏡。
- 像素角色：AI 圖重新對齊到真正的像素網格（《三千年夜》）。
- 放大用 Real-ESRGAN；用深度估計模型把一張圖拆成視差圖層（Rain Station）。
- **保留生成器的浮水印與 AI 標示**，不要去除。

### 用真的素材

- 介面、Logo、產品畫面用真的（重建或截圖），不要編造（rexan_wong、OpusClip）。
- 有 Logo 時，宣傳片的導引線與母題會從 Logo 的意義衍生；沒有 Logo，它會發明無關的品牌元素（阿珍）。
- 給的圖片要「發揮作用」：去背、標註、高亮、點擊狀態變化、模型爆炸圖、線框與實體切換，不是靜態展示（阿珍）。

## 3D

- 網頁 3D 的實際效果常不如預期（可爱归归計畫做全 3D 時重新規劃）。重度 3D 用 Blender。
- **Blender**：用 MCP 互動建場景與檢查，正式渲染用無頭 `blender -b`，可重現。執行任意 Python 前先存檔。第一個測試：叫它改一盞燈，確認 Blender 的畫面真的變了（仪绘士BY）。怎麼接回片子見 [10](10-render.md#其他工具做的畫面)。
- 從照片建模：先用便宜的視覺模型在 three.js 建粗模，再用旗艦視覺模型精修；沒有視覺能力的模型會做出零件分離的模型（仪绘士BY）。
- 景深用多次取樣累積，不要用深度圖模糊（Multiplane）；以 2 倍解析度渲染再縮小（lemo-opuscar）。
- 素材授權：Poly Haven 是 CC0；Sketchfab 每個模型授權不同，要逐一確認並列入 CREDITS。

## 質感與可讀性

- 顆粒、暗角、色差、低幀率屬於**選定的風格**，不是通用的「質感濾鏡」（OpusClip）。
- 顆粒加在網頁裡會讓畫面難以壓縮、渲染變慢；可以改在 ffmpeg 加（lemo-opuscar）。本專案引擎的顆粒以幀編號為種子，確保可重現。
- **手機可讀性**：把畫面縮到 360 px 寬看（xilo）；主體至少占畫面三分之一；不要滿屏小字。
- 檢查靜態關鍵畫面：如果主體一眼看不出來，先修構圖，再加動態（OpusClip）。

## 禁用清單範本

每張風格卡都要有禁用清單。長長的「不要」清單其實是傷疤組織：每一條都是之前失敗過的地方（op7418 的觀察）。可以從這些開始：

- 置中大字＋漸層背景＋全部同時淡入
- 交叉溶解、模糊淡入、3D 翻轉、彈跳緩動、停超過 1 秒的畫面（twoclipping 的發表片禁用清單）
- 通用 SaaS 插畫、企業圖示、寫實照片感、賽博龐克、過量霓虹、AI 漸層、素材圖感（leo_xiaolei）
- 霓虹賽博、發光大腦、數字雨、光暈湯、粒子星雲（mexicat）
- 真實品牌與商標（除非你擁有權利）
